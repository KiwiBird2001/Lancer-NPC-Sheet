# Lancer NPC Sheet
A tool to easily set up printable NPC sheets for the Lancer TTRPG. Does *not* support traits, weapons, and systems as of 2026-11-02.

[Example](https://kiwibird2001.github.io/Lancer-NPC-Sheet/) (Uses a PC mech since Lancer NPCs are paid content.)

Optimized for *Microsoft Print to PDF* with no margins.
## How to use
* Download a local copy of the project.
* Edit `index.html` and input the NPC statistics in the `npc_name` and `npc` objects.
* Save your changes and open the file in your browser of choice.
* Press CTRL + P and select "Microsoft Print to PDF" as the *Destination*.
* Set *Margins* to "None" (sometimes found under *More settings*.)
* Print your NPC.
